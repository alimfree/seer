# OG Image (Social Share Preview)

Place a file called `og-image.png` in this directory.

**Specs:**
- Size: 1200 x 630 pixels (required for LinkedIn, Facebook, Twitter, iMessage, Slack)
- Format: PNG
- Content suggestion: "Seer Mobility" logo/wordmark + "NEMT Billing & Revenue Cycle Management" tagline on a clean background matching your site's color palette (#f8f9ff background, #000b13 text). See `og-image.svg` in this directory for a source you can rasterize to `og-image.png`.
- Keep text large and readable at thumbnail size (the image is often shown at 600x315 or smaller)

**Test your OG tags:** After deploying, paste your URL into:
- https://www.opengraph.xyz/
- https://cards-dev.twitter.com/validator
- LinkedIn post composer (paste URL, see preview)
